# טופס מועמדות לשידוכים בעזרת ה' | שאלון אינטראקטיבי

דף נחיתה אינטראקטיבי, מכבד ויוקרתי לבדיקת התאמה ושידוכים לבעלי תשובה ולציבור הדתי/מסורתי.

## 🌟 מאפיינים עיקריים
- **כל 7 פרקי השאלון במדויק:** פרטים אישיים, סטטוס ומשפחה, עולם התורה, שמירת נגיעה וצניעות, אופי וזוגיות, מידות ועבודת הנפש, והתאמה לשידוך.
- **שאלות עומק מתקדמות:** סגנון תקשורת בעת אי-הסכמה, שפת האהבה, שותפות בניהול הבית, גמישות וויתור, הכרת הטוב וקבלת ביקורת.
- **כרטיס שידוכים מעוצב בלייב (Live Preview Card):** כרטיס מועמד יוקרתי שמתעדכן בזמן אמת תוך כדי מילוי הטופס.
- **העלאת תמונה עדכנית:** גרירה ושחרור, תצוגה מקדימה והסרה נוחה.
- **יצוא ישיר ל-WhatsApp:** הודעה מעוצבת ומוכנה לשליחה לשדכן/ית בקליק אחד.
- **הדפסה ושמירה כ-PDF:** עיצוב ייעודי להדפסה נקייה של הכרטיס או הטופס המלא.
- **שמירה אוטומטית מקומית (`localStorage`):** הנתונים נשמרים בדפדפן ומאובטחים.
- **טיפוגרפיה מותאמת עברית:** גופני Rubik ו-Assistant לקריאות מושלמת בכל מכשיר.
